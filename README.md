# @makechart/pie-bubble

> **Superseded by `@makechart/bubble`.** This package is an early, simpler version kept only for
> charts that already reference it. New charts should use `@makechart/bubble`, which covers the same
> use case: bind two or more columns to its `area` dimension to draw each bubble as a pie. It also
> supports any number of wedges, grouping and a wedge legend, while this package is limited to a
> `left` and a `right` value.
>
> No new features are planned here. makechart's built-in "pie bubble" chart is provided by
> `@makechart/bubble`.
